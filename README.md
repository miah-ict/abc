# 🚀 ABC - Miah ICT

Welcome to the **ABC** project! This is a modern, responsive web application built with the powerful PERN stack (PostgreSQL, Express, React, Node.js). 

## ✨ Features

*   **🌐 Stunning Landing Page**: A beautiful, modern, and engaging public-facing landing page built with React and Tailwind CSS v4.
*   **🛡️ Super Admin Portal**: A comprehensive and secure dashboard for managing users, schools, programs, and more.
*   **⚡ High Performance**: Fast and responsive, ensuring a smooth user experience.
*   **🎨 Modern Design**: Implements sleek UI/UX principles, including glassmorphism and smooth micro-animations.

## 🛠️ Technology Stack

*   **Frontend**: React (Vite), TypeScript, Tailwind CSS v4
*   **Backend**: Node.js, Express.js
*   **Database**: PostgreSQL

## 🚀 Getting Started

1.  **Install dependencies**: `npm run install:all`
2.  **Initialize the database**: `npm run db:init`
3.  **Start the development servers**: `npm run dev`
